- **Select and copy terminal text by touch.** On a phone or a touch screen, a long press on text selects its word, with a handle at each end and a bar with Copy, Paste and Select all. Drag a handle, or keep the finger down and move it, to change the selection; held past the top or bottom, it scrolls. A tap ends it. A long press on an empty spot still shows only Paste. On Android the keyboard no longer pops up over the selection. Paste goes through the same checks as a right-click paste, so it still asks before pasting several lines. (Their [#405](https://github.com/SinaXhpm/submarine/pull/405); [#288](https://github.com/paulm981/Submarine/issues/288))
  - It works in a terminal shown in the AI side pane too.
- **On a Mac, a right-click on a file name in a terminal opens the file-path menu** (Paste, Copy path, Edit locally), as it does on Windows and Linux. Before, a right-click on a Mac always pasted. Elsewhere it still pastes. (Their [#405](https://github.com/SinaXhpm/submarine/pull/405); [#288](https://github.com/paulm981/Submarine/issues/288))
