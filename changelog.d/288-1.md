- **Closing the app no longer leaves its profile locked.** With "A copy in a folder" on and a slow cloud drive, opening the app again could say the profile was open in another window. Now the app lets go of the profile as soon as its last save is done, then waits up to 5 seconds for the copy to arrive in the folder. (Their [#401](https://github.com/SinaXhpm/submarine/pull/401); [#288](https://github.com/paulm981/Submarine/issues/288))
- **Copy and paste files through the built-in Remote Desktop client.** With "Share the clipboard" on, files copied on the server can be pasted on this computer, and files copied here can be pasted on the server. A copy over 100 MB waits until you press "Bring them here". Nothing of this computer goes to the server unless you paste there. (Their [#409](https://github.com/SinaXhpm/submarine/pull/409); [#288](https://github.com/paulm981/Submarine/issues/288))
- **A click beside the "file exists" prompt no longer cancels the upload or download.** Its buttons, its × and Escape still answer it. (Their [#414](https://github.com/SinaXhpm/submarine/pull/414); [#288](https://github.com/paulm981/Submarine/issues/288))
- **On Windows, a paste waits a little longer when another app is holding the clipboard,** up to half a second, before it says "Another app is using the clipboard." The clipboard is now read by the original project's code, which does what the fork's did. (Their [#418](https://github.com/SinaXhpm/submarine/pull/418); [#288](https://github.com/paulm981/Submarine/issues/288))
