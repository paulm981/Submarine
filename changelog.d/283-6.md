- **A Library command can now be Secret.** Its text shows as dots in the Library and in a server's Library panel, and editing it has a Show button. A secret has Run but no Paste, and Run always asks first, with the text hidden until you press **Show command**. A secret is only hidden on screen: it's kept and synced like any other command, to everyone in a shared profile, not locked away like a saved password. Once it runs, it's in the server's shell history like anything you type. The AI tools can't read the Library, and a run isn't logged or kept in Submarine's command history. (Their [#356](https://github.com/SinaXhpm/submarine/pull/356); [#283](https://github.com/paulm981/Submarine/issues/283))
- **Library commands can have tags**, typed as a list with commas (up to 20, each up to 32 characters). A server's Library panel filters by them, with chips for All, Secrets and each tag, and the Library's search finds tags too. You can also add commands and notes from a server's Library panel now. (Their [#356](https://github.com/SinaXhpm/submarine/pull/356); [#283](https://github.com/paulm981/Submarine/issues/283))
- **Submarine is now based on the original project's 0.5.1,** with every change they've made up to it. Releases are numbered from **v0.5.1-fork.1**. On Windows the setup offers to update 0.5.0 to 0.5.1, and Android sees it as a newer version too. (Their [#389](https://github.com/SinaXhpm/submarine/pull/389); [#283](https://github.com/paulm981/Submarine/issues/283))
