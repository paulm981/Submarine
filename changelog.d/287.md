- **Add to the Library from a server's tab.** A server's Library panel has a **+** that adds a command, a secret command or a note right there. A new command is for this server unless you pick **All servers**. (Their [#392](https://github.com/SinaXhpm/submarine/pull/392); [#287](https://github.com/paulm981/Submarine/issues/287))
- **Tabs show what a program calls its terminal,** such as the folder you're in or the file you're editing, after the tab's name: `web-01 · ~/logs`. The name always comes first, and a long title is cut, with all of it in the hover text. It comes from the server, so hidden and right-to-left characters are taken out, and a title longer than 4,096 characters is ignored. **Show program titles on tabs** in Settings › Terminal turns it off. (Their [#393](https://github.com/SinaXhpm/submarine/pull/393); [#287](https://github.com/paulm981/Submarine/issues/287))
- **A server's tab can open without connecting** when you unlock the profile. The server form's Autostart switch is now **At startup**: Don't open, Open the tab, or Open and connect (SSH only, as before). A tab that opened this way waits with **Connect** and **Close** until you connect it there, from its menu, or by opening the server from the session tree, the server list, Broadcast or the AI's Share. Closing it, or quitting or locking, never asks about it, since it has no connection to end. (Their [#394](https://github.com/SinaXhpm/submarine/pull/394); [#287](https://github.com/paulm981/Submarine/issues/287))
- **Change the text size without opening Settings:** pinch a terminal, use Ctrl + wheel over it (⌘ + wheel or a trackpad pinch on a Mac), or the − and + keys on a phone's key bar. It's the size in Settings, so every terminal follows. Over a terminal, Ctrl + wheel now changes the size instead of scrolling. (Their [#395](https://github.com/SinaXhpm/submarine/pull/395); [#287](https://github.com/paulm981/Submarine/issues/287))
