- **A light look.** Pick a light background in Settings › General, or one of the new presets Snow, Paper and Silver, and the whole interface turns light: text, tabs, panels, menus and dialogs, the fork's own screens too (the session tree, Kept sessions, Push and pull files, the AI panel and side pane, the server form). Terminals and remote desktops keep their own colors, and so does what's drawn over a terminal, a terminal docked in the AI side pane included. The dark look is unchanged. (Their [#415](https://github.com/SinaXhpm/submarine/pull/415); [#288](https://github.com/paulm981/Submarine/issues/288))
- **A folder mirror can take only some files, go one way, or run once.** "Only these" and "Skip these" take patterns such as `*.sql`, `db/`, `backups/**/*.sql`, or a word anywhere in the path; the server's form has the same fields. A mirror can copy both ways, only up to the server, or only down from it: down runs once and never writes to the server. Any mirror can run once: it copies what the preview lists, then stops. (Their [#416](https://github.com/SinaXhpm/submarine/pull/416); [#288](https://github.com/paulm981/Submarine/issues/288))
  - Each list takes at most 100 patterns, each at most 512 characters. A mirror with more says so and doesn't start: a saved mirror syncs with a shared profile, so its lists can come from someone else.
  - A mirror down from the server still never puts a file in a folder that runs programs at login.
  - Removing a skipped folder on this computer no longer removes it on the server. A failed mirror keeps its error until you dismiss it. On Windows, a mirror started from its saved card no longer gets a second card.
- **Submarine is now based on the original project's 0.5.2,** with every change they've made up to their #419. Releases are numbered from **v0.5.2-fork.1**. On Windows the setup offers to update an older version to 0.5.2, and Android sees it as a newer version too. (Their [#410](https://github.com/SinaXhpm/submarine/pull/410); [#288](https://github.com/paulm981/Submarine/issues/288))
