- **AI git read-only safety hardening** ([#302](https://github.com/paulm981/Submarine/issues/302)): `git status`, `git diff`, `git log`, `git show`, and `git describe --dirty`/`--broken` now ask before running because repository `.git/config` or `.gitattributes` settings can invoke programs (`core.fsmonitor`, `diff.external`, `textconv`, `gpg.program`), while `git rev-parse`, `git describe` (without `--dirty`/`--broken`), and read-only `git branch` flags still run.
