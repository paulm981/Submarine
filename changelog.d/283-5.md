- **You can now change the keyboard shortcuts, in Settings › Keyboard shortcuts.** A table lists the app's own shortcuts: next and previous tab, open a server, and the terminal's new, close, find, command history, clear, copy, paste and select all. Each can have several keys, or none, and goes back to its default with one click. A key that types, or that the system takes, is refused. The keys are kept on each device. (Their [#374](https://github.com/SinaXhpm/submarine/pull/374); [#283](https://github.com/paulm981/Submarine/issues/283))
- **The shortcuts start as the keys you already had:** Ctrl+Tab and Ctrl+Shift+Tab, Ctrl+Shift+W, Ctrl+Shift+K, Ctrl+Shift+Plus and the rest (⌘ on a Mac). Ctrl+Tab still steps through Home, the Broadcast tab, then the servers. Two keys are new: **Ctrl+Shift+T** (⌘T on a Mac) opens the + menu to open a saved server from anywhere, and **Ctrl+Insert** copies on Windows and Linux. (Their [#374](https://github.com/SinaXhpm/submarine/pull/374); [#283](https://github.com/paulm981/Submarine/issues/283))
- **Three of Submarine's keys stay fixed:** **Ctrl+Shift+J** (jump to a tab by name), **Ctrl+Shift+L** (the AI side pane) and **Ctrl+Shift+P** (pause a Broadcast tile). The table won't give them to anything else, and says so under its list. Typing in a terminal is as fast as before: a plain key never reaches the table. (Their [#374](https://github.com/SinaXhpm/submarine/pull/374); [#283](https://github.com/paulm981/Submarine/issues/283))
- **Android with a hardware keyboard:** a keyboard cover, or a USB or Bluetooth keyboard, puts the cursor in a new terminal straight away, and capitals and characters typed with Shift or AltGr now reach the terminal. Without one, the terminal still waits for a tap, so the on-screen keyboard doesn't come up unasked. (Their [#377](https://github.com/SinaXhpm/submarine/pull/377); [#283](https://github.com/paulm981/Submarine/issues/283))
