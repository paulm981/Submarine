- **Disconnect stops everything the tab had running.** Docker's live logs, Live Edit watchers, and archive and extract jobs end with the tab. Each kept the connection open, and `docker logs -f` went on running on the server. Kept tmux and screen sessions on the server are left as they are. (Their [#388](https://github.com/SinaXhpm/submarine/pull/388); [#283](https://github.com/paulm981/Submarine/issues/283))
- **Locking the profile, or reloading the window, stops every folder mirror, Live Edit watcher and Docker log stream,** and a reload closes FTP tabs too. Unsent Live Edit changes are kept in **Submarine unsent edits**, as before. (Their [#388](https://github.com/SinaXhpm/submarine/pull/388); [#283](https://github.com/paulm981/Submarine/issues/283))
- **A tab's port forwarding rules no longer come back on another profile's server.** Locking clears them, and stopping a remote forward now ends the connections it was carrying. (Their [#388](https://github.com/SinaXhpm/submarine/pull/388); [#283](https://github.com/paulm981/Submarine/issues/283))
- **When a connection drops, its logins to the jump host close with it,** instead of staying open until you press Reconnect. A login shared with other tabs stays for them. Ping still checks a server behind that jump host while it reboots: it keeps its own hold on the jump host while you're pinging. (Their [#388](https://github.com/SinaXhpm/submarine/pull/388); [#283](https://github.com/paulm981/Submarine/issues/283))
- **Live Edit on an FTP tab uploads every save,** not only the first. (Their [#384](https://github.com/SinaXhpm/submarine/pull/384); [#283](https://github.com/paulm981/Submarine/issues/283))
