- **SSH tabs behind the same jump host share one login to it.** Opening a folder of servers behind a jump host asks for its password or code once, not once per tab, and the jump host sees one login for up to 16 tabs. A jump host that records sessions now sees those tabs as one login. Turn it off in Settings › Servers & sessions. ([#237](https://github.com/paulm981/Submarine/issues/237))
